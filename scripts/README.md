# scripts/

Every script, grouped by what it does. Descriptions come from each file's own header; open the file for flags and details. Agents: look here before searching, and add a line when you add a script (`node scripts/check-scripts-index.mjs` fails if one is missing).

`npm` aliases: `preflight`, `video-status`, `sweep`, `music-start`, `research`, `setup-voice`, `clone-voice`, `listing`, `listing-voice`, `listing-render`, `review` (`review/build.mjs`). `npm test` runs the checks marked **test** below on every PR (CI); the rest need media or full git history and run locally.

## Prep: a recording becomes a video's inputs
| Script | Does |
|---|---|
| `prep-video.py` | Prepares a new talking-head video for MortgageReel: Whisper words, proxy, matte. Run first. |
| `recordings.py` | Where a video's recording files live (the Python copy of `src/mortgage/recording.ts`). |
| `reframe.py` | Finds the face in a landscape or square recording so the 9:16 proxy crops around it. |
| `brief.mjs` | What a video is about, as numbers the template selector scores. |
| `select-template.mjs` | Ranks the designs for one video and writes the top 3 with reasons; `--report` compares each `selection.json` top pick with the design made. |
| `matte-headless.mjs` | Background removal without opening the page: drives `review/matte.html` in Chrome for Testing (`@remotion/renderer` openBrowser, WebGPU on) for `<slug>` (`--bench <3-60>` times it and saves nothing; `--headed` opens a visible window when headless has no GPU); prints `== <status>` as it goes; exit 0 saved, 1 stopped, 2 couldn't start. `--selftest` in npm test | **test** |
| `mcp-smoke.mjs` | `npm run mcp:smoke -- <slug> [--matte] [--render]`: drives the real MCP server (stdio) through its tools on one video and writes `out/mcp/smoke-<slug>.md` (PASS / FAIL / SKIP per step) to paste to Claude. Changes nothing: `edit patch` without confirm, the matte as a bench; renders only with `--render`. Footage steps SKIP without `source.mp4` | **run** |
| `music-start.mjs` | Where a music track gets going, so `edit.json` `music.startMs` can skip its intro. |
| `migrate-assets.py` | Moves each recording into `public/recordings/<id>/` (the asset contract). |
| `migrate-footage-to-library.mjs` | Imports per-slug `voice/footage/` files into the source library. |

## Render and publish
| Script | Does |
|---|---|
| `preflight.mjs` | Runs before every render (called by `render-video.py`): fonts, `edit.json` mistakes, pacing off, then `check-schema`, speech cuts and pacing (a check that crashes blocks). |
| `render-video.py` | Renders a MortgageReel video end to end: master, -14 LUFS mix, mobile copy, thumbnail, `.srt`, QC sweep, publish. |
| `sweep-render.mjs` | Sweeps a finished render for every visual change so QC sees what `edit.json` produced (`sweep.json` `cuts` lists every scene change). `--start <s> --end <s>`: a focus window, same frame budget so denser, every time absolute (claude-video `auto_fps_focus`, MIT). |
| `publish-video.mjs` | Hands a render to Daniel: a copy named after its topic, a caption file and a `<Topic> - COMPLETED.txt` marker (finished when, which slug, approve before posting) in `2 - FINISHED VIDEOS`; refuses a render older than its on-screen inputs (`<slug>.inputs` stamp from `render-video.py`) and another slug's same-title files (unowned older files: only with `--claim`, else exit 4 naming the videos with that title; the owner record is written under `.publish-slugs.lock`); a `rendering` stamp (a render that stopped part way) is refused, even with `--stale-ok`. |
| `publish-post.mjs` | After COMPLETED and Daniel's yes: names the Drive files (`<date>_<Title-slug>_Video.mp4`, `_Caption.txt`, `_Thumbnail.png`), copies them into `config/publish.json` `drive.syncDir`, and keeps the ledger `team/07_published.json` (`plan` / `stage` / `mark`) so a retry never repeats a YouTube upload or a Facebook post; `plan` stops on a missing file, no final compliance PASS, or an unset config value. The Drive, YouTube and Facebook calls are the orchestrator's MCP calls. Self-test in `check-publish.mjs`. |
| `export-srt.mjs` | Writes `out/videos/<slug>/<slug>.srt` using the same cuts as the render. |
| `export-chapters.mjs` | Prints a YouTube/Facebook chapter list timed on the output. |
| `promote-design.mjs` | Promotes a proven design to a reusable template (checks, then registers). `--browser <path>` / `FINHUB_BROWSER`: stills in an installed headless shell (`--gl=swangle`). The faceless fixture without media gets voice-video's no-footage placeholders (navy `source.mp4`, transparent cut-out, VP9; `scratch-public.mjs`): navy where faceless-test has stock footage, so a sandbox pass proves the render, not the look over footage (the log says SANDBOX PICTURE); the talking-head fixture without its recording and matte is INCOMPLETE, a failure, never promoted. |
| `report-promotion-drift.mjs` | Report only (exit 0, writes nothing): each promoted design's commits since the commit that set its `promoted` value (its folder plus every shared file its index imports, e.g. `golden.ts`, `classic/Cues.tsx`); a shallow clone says "no history". |
| `video-status.mjs` | Where each video's team run stands, read from the files the production team writes; with a slug, also the per-agent totals of `team/usage.jsonl`. |
